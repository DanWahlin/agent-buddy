Add a character pack

Three steps, no folders to find.

  1. Download the .acpk file of the character.
  2. In Agent Buddy, open Settings, select the Characters tab, select Add character pack, and choose the file. Agent Buddy copies the pack into its own folder, so you can then delete the download.
  3. Select Install to put the character on your device, or Show on desktop to use it in the desktop app.

A free preview has a Preview tag at the character's feet. The full character has the same id, so when you add it later, it replaces the preview. From a source checkout, you can also run npm run character path/to/pack.acpk.
