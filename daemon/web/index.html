    Device not found?

    For a paired Wi-Fi device, keep it powered on and on the same network as this computer. Agent Buddy checks its connection automatically.

    Try another USB data cable or USB port. Close any serial monitor that uses the device.

    On Linux, check serial-port permissions. On Windows, connect USB to the Windows desktop app, not to a WSL terminal.

    USB detection cannot confirm the board model. Only install firmware on the supported Waveshare device.

    Install firmware

    Firmware download needs internet access. The app includes the installer; Python and Node.js are not required.

    Installing firmware replaces the device firmware and partition table. Back up anything you need from other firmware first.

    Connection or download failed?

    Check your internet connection and USB data cable. Close serial monitors. If the board does not respond, hold BOOT while you reconnect USB, then release BOOT and detect it again.

    If firmware installed but character setup failed, retry only the character installation.
